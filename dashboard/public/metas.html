Cumprimento das metas

Metas - onde cada estado já chegou.

Este painel não classifica os estados entre si: para cada meta da Estratégia com patamar mensurável, ele mostra se o estado já a cumpre e, quando não, quanto falta. Os prazos das metas vão de 2030 a 2050, então o quadro é a posição de hoje no caminho até o horizonte, não um resultado final.
